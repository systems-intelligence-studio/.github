# Systems Intelligence Studio

We design, build and operate systems that turn data into reliable decisions.

Our direction is superintelligent systems that serve the people who decide.
Today that means data and AI systems that run in production, show their
evidence and leave every decision to a person.

## How we work

- A written specification before the code.
- An independent review before a change counts as done.
- A verification record behind every result we claim.
- Nothing published that a repository cannot show.
